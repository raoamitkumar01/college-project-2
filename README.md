# 🧮 Calculator Website

This is a simple calculator made using HTML, CSS and JavaScript.

## 📌 About Project

This project is a basic calculator that can perform:

- Addition
- Subtraction
- Multiplication
- Division
- Clear display

The calculator runs in browser and does not use any backend.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- VS Code
- GitHub

## ⚙️ Features

- Button based calculator
- Display screen
- Real calculation using JavaScript
- Simple UI design
- Beginner friendly code
